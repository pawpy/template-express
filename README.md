# Express starter

A minimal [Express](https://expressjs.com) server in TypeScript.

## Run it locally

```sh
npm install
npm run build
npm start
```

Then open http://localhost:8080. `GET /health` answers `ok` for health checks.

## Deploying

| Step | Command |
| --- | --- |
| Build | npm run build |
| Start | npm start |

## Environment variables

| Variable | Meaning |
| --- | --- |
| `PORT` | Port to listen on. Default: 8080. |
